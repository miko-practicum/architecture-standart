## Зависимости для RoadMap

1. Сначала нужен управляемый источник ставок в АБС и контракт публикации ставок.
2. Затем можно запускать `Rates API / Rate Cache`.
3. После появления API внутренний кол-центр может показывать ставки операторам.
4. Файловый экспорт на SFTP можно делать параллельно с интеграцией внутреннего кол-центра.
5. Сайт и интернет-банк подключаются к тому же источнику ставок перед запуском онлайн-заявок.
6. Годовой целевой этап добавляет автоматическое открытие депозитов без участия бэк-офиса.
